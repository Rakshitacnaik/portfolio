## Run Locally

This portfolio is a static website. To view it on your computer:

1.  Clone or download the project repository.
2.  Open the project folder.
3.  Open `index.html` in your web browser.

If you use Visual Studio Code, you can also open the folder and launch
`index.html` using the Live Server extension.

## Deployment

The portfolio is hosted on **Vercel**.

For a basic static HTML deployment, ensure that the main page is named
`index.html` and is located in the configured project root or output
directory. Push updates to the connected repository or redeploy the
updated project through Vercel.
